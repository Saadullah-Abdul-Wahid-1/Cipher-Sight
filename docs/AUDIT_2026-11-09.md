# ImageHunter 1.0.0-rc2 implementation and security audit

## Implemented in this build

- ZIP member extraction uses incremental reads, per-member and aggregate output caps, and validates actual output length and compression ratio. ZIP header sizes are treated as untrusted hints.
- ZIP path traversal, symlink, encrypted-member, entry-count, recursion-depth and total-byte checks remain enforced.
- TAR regular-file recovery and GZIP stream recovery are bounded; no archive paths are written to disk.
- TIFF byte order, header, bounded IFD chain, entry counts and tag summaries are parsed.
- WebP RIFF chunk boundaries, declared size and trailing data are inspected.
- Optional OCR and QR/barcode processing is available through `pytesseract` and OpenCV. It is disabled by default with `vision_analysis_enabled: false` to avoid slow scans and unexpected external Tesseract executable requirements.
- Optional JPEG DCT analysis uses `jpegio` to report quantized coefficient statistics. It does not decode a payload or claim universal JPEG steganography detection.
- Optional PDF export is attempted when ReportLab is installed. Failure does not prevent JSON/HTML report generation.
- Flag triage exposes analyst-verified results plus strong and weak candidates. A pattern match is never automatically verified.
- Cancellation signal is available through `AnalyzerContext`; the vision analyzer checks it between frames. Existing analyzers that do not poll the signal remain non-interruptible while executing.

## Optional installation

```bash
pip install -e ".[pdf,ocr,vision,jpeg-dct]"
```

OCR additionally requires the Tesseract executable installed on the operating system. Enable OCR/QR analysis in the settings JSON:

```json
{"vision_analysis_enabled": true}
```

## Known limitations

- JPEG DCT output is statistical triage, not an F5/JSteg/OutGuess decoder and not proof of hidden data.
- OCR and barcode capability depends on optional third-party packages and, for OCR, an external Tesseract installation.
- TIFF parser intentionally bounds IFD traversal and reports tag descriptors; it does not decode every TIFF tag value or every BigTIFF variant.
- WebP parser inspects RIFF chunks and boundaries; it is not a complete decoder for all WebP metadata subformats.
- TAR/GZIP recovery is read-only and bounded; special files and links are not extracted.
- Cancellation is cooperative. The frame-based vision analyzer polls it between frames; legacy analyzers may only stop between analyzer invocations.
- License selection remains pending; no LICENSE file was added.

## Validation record

Unit tests: 204 passed, 7 subtests passed. Integration modules: 85 passed, 22 subtests passed when run individually. Compile check, CLI smoke checks, PDF generation, wheel build (no build isolation), and sdist build passed. A full combined integration invocation printed its passing summary but the process did not exit cleanly in this sandbox; individual integration modules were used to isolate results. Manual GUI/Windows, clean-venv installation, and real-world optional OCR/QR/JPEG-DCT validation remain required.
