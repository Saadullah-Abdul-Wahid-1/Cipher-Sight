# CipherSight

**CipherSight** is an offline image-forensics and CTF steganography toolkit by RootHackersLab.

Current release candidate: **1.0.0rc4**. It investigates images and supported derived artifacts for metadata,
structural anomalies, hidden pixel data, encoded strings, embedded files, and CTF-style flag candidates.

> This is an analyst-assistance tool. A detected flag-shaped string is a candidate, not proof that a challenge accepts it.
> CipherSight does not upload scanned images or execute recovered files.

## Features

- Read-only input handling with SHA-256 integrity verification.
- Image identity and format/extension mismatch detection.
- PNG, JPEG, and BMP structural inspection; bounded TIFF IFD and WebP RIFF chunk parsing.
- EXIF and PNG text metadata extraction with bounded processing.
- Printable strings, clue phrases, and ranked password/passphrase leads.
- LSB, bit-plane, channel, and bounded advanced pixel-domain experiments.
- GIF frame timing/disposal, changed-pixel ratios, and per-frame red-channel LSB candidate checks.
- Indexed-palette inventory and palette-index LSB candidate checks.
- Embedded signature discovery, bounded appended-payload recovery, and safe ZIP/nested-ZIP/TAR/GZIP follow-up.
- Bounded recursive decoding and evidence provenance.
- JSON and HTML reports, plus optional PDF export when ReportLab is installed.
- CLI, desktop UI, and local web UI.

## Requirements and installation

- Python 3.10 or newer.
- Required packages: Pillow, NumPy, and ReportLab (PDF reporting).
- Optional: OpenCV + pytesseract for QR/barcode and OCR analysis; `jpegio` for JPEG DCT statistics.
- OCR additionally requires the external Tesseract executable; installing `pytesseract` alone is not sufficient.

Create an environment and install:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
python -m pip install -e .
# Optional extras: python -m pip install -e ".[ocr,vision,jpeg-dct]"
```

For a source checkout, `python main.py` can be used instead of the installed `imagehunter` command.

## Usage

```bash
python main.py --version
python main.py check-deps
python main.py check-tools
python main.py scan path/to/image.png
python main.py scan path/to/image.png --mode deep --workdir ./workspace
python main.py gui
python main.py web --port 8765
```

A scan writes JSON and HTML reports to its per-scan workspace. Treat reports and candidate exports as potentially sensitive:
they may contain recovered strings, metadata, GPS coordinates, and challenge clues.

## Security and limitations

- Original input is not intentionally modified; a read-only working copy is scanned and the original is re-hashed.
- Recovered files are never executed.
- ZIP extraction is bounded and rejects unsafe paths, links, encrypted entries, and suspicious members.
- OCR and QR/barcode analysis are optional and disabled by default. Install `.[ocr,vision]` and set `vision_analysis_enabled` to `true`; OCR also requires the Tesseract executable.
- PDF export is included with the standard install. JPEG DCT statistics are optional: install `.[jpeg-dct]`; these are statistical indicators, not a universal JPEG stego decoder.
- TIFF parsing is bounded to classic TIFF IFD structures; BigTIFF and full tag-value decoding are not implemented. WebP parsing covers RIFF chunk boundaries, not every metadata subformat.
- Cancellation is cooperative. The vision analyzer checks between frames; a currently running OCR or legacy analyzer may finish before cancellation is observed.
- A clean scan does not prove that an image contains no hidden data. Steganography methods are numerous and challenge-specific.

## Responsible use

Use CipherSight only on files you own, CTF challenges, training materials, or files you are explicitly authorized to examine.

## Run the localhost web interface

CipherSight includes a browser-based interface that runs entirely on your own computer. It does not require cloud hosting and the web server binds to `127.0.0.1` only.

### Windows

1. Extract the ZIP into a normal folder.
2. Install Python 3.10–3.13 (enable **Add Python to PATH** during installation).
3. Double-click `CipherSight_Localhost.bat`.
4. On first launch, the script creates `.venv` and installs the project dependencies.
5. Open `http://127.0.0.1:8000/` if the browser does not open automatically.
6. Keep the terminal window open while using CipherSight. Press `Ctrl+C` in that window to stop it.

### Linux / macOS

Run `./run_ciphersight.sh` from the extracted project directory. The script creates/reuses `.venv`, installs the project, and starts the local server at `http://127.0.0.1:8000/`.

### Manual launch

```bash
python main.py web --port 8000
```

The browser UI is served locally from the Python package; its HTML, CSS and JavaScript do not depend on a CDN. The interface uses a 3D-inspired visual style (CSS depth, lighting and motion), not a WebGL 3D scene. The analysis engine remains the source of truth: the UI displays the scanner's actual results and does not fabricate findings.
